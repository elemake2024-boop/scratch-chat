# リアルタイムチャット

## 起動

```sh
npm install
npm start
```

ブラウザーで `http://localhost:3000` を開きます。メッセージは WebSocket で送受信し、サーバーのメモリー上に保持します。

接続すると「匿名○○#数字」の名前で参加します。画面上部の名前欄を編集するとユーザー名を変更できます。吹き出しの色も画面上部で変更できます。メッセージへの返信、自分の投稿の削除、8MB 以下の画像・動画の送信に対応しています。画面共有は画面下部のアイコンから開始します（ブラウザーの許可が必要です）。

メッセージなどを入力していないときに `6780` と入力すると全員の画面をロックし、もう一度入力すると解除します。ロックを開始した人にはロック画面を表示せず、ヘッダーに「ロック中」と表示します。接続が一時的に切れて再接続しても、ロック状態は維持されます。

入力欄にフォーカスがない状態で `888` と入力すると管理者になり、全員のコメントに削除ボタンが表示されます。自分のコメントの削除は通常どおり可能です。

接続が切れた場合は自動で再接続します。バックグラウンドタブの接続維持のため、サーバーは定期的に疎通確認を行います。
