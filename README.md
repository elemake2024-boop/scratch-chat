# リアルタイムチャット

## 起動と環境変数

Node.js 20 以降を使用し、以下を設定して起動します。

```sh
npm install
npm start
```

必須の環境変数:

- `APPWRITE_ENDPOINT`
- `APPWRITE_PROJECT_ID`
- `APPWRITE_DATABASE_ID`
- `APPWRITE_TABLE_ID`
- `APPWRITE_BUCKET_ID`
- `APPWRITE_API_KEY`
- `PORT`（省略時は `3000`）

Appwrite のデータベースにテーブルを作成し、`senderId`, `name`, `color`, `text`, `replyTo`, `fileId`, `fileName`, `fileMime` の各列を Text 型で用意してください。`senderId` には検索用インデックスが必要です。サーバー用 API キーにはテーブル読み書きと Storage ファイルの読み書き権限を付与してください。

Storage バケットでは、匿名Appwriteユーザーのファイル作成を許可し、ファイル単位の権限を有効にしてください。最大ファイルサイズを330MB以上に設定し、画像・動画のMIMEタイプを許可してください。クライアントからの直接アップロードを許可するため、Appwriteプロジェクトのプラットフォームにチャットの公開ドメインを登録してください。アップロードファイルはチャット利用者が閲覧でき、アップロードした匿名ユーザーが自身の未投稿ファイルを削除できる権限で保存されます。

## 機能

メッセージはAppwriteのテーブルに保存され、参加時は直近72時間分を古い順に読み込みます。起動時と毎時、72時間以上経過したメッセージを1件ずつ削除し、添付ファイルがあれば合わせて削除します。Appwriteへの読み取りアクセスは起動時と1日ごとに実行します。

名前・色変更、返信、投稿者本人または管理者による削除、画面共有に対応しています。表示名はブラウザーに保存され、ページを再読み込みしても維持されます。画面入力時以外に `6780` を押すとロックを切り替え、`888` で管理者モードを有効化します。接続が切れた場合は自動で再接続し、サーバーから15秒ごとにheartbeatを送信します。

入力欄の＋ボタンから写真・動画の添付、または次の自分のメッセージのピン留めを選べます。ピン留めは `888` で管理者になった利用者だけが設定でき、次に送る自分のメッセージが全員の画面上部に表示されます。別のメッセージをピン留めすると前のピンは置き換わります。ピン留め状態はサーバーのメモリー上に保持され、サーバー再起動時に解除されます。

画像はブラウザーで縮小・WebP圧縮し、動画は長辺1280px以下、約1.25Mbpsの映像ビットレートで圧縮してから、Appwrite Storageへ直接アップロードします。GIF・SVG・APNG画像はアニメーションやベクター形式を維持するため再エンコードしません。添付の上限は330MBです。

Renderなどの死活監視には `GET /ping` を利用できます。ステータス `200` と本文 `OK` を返します。
